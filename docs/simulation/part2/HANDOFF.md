# 第三阶段交接清单

第二阶段已完成真值位姿、真实仿真点云、地图对齐和目标/轨迹展示；15 次轨迹验收通过。
时间/系数同步与加速度收敛已修复，复验命令及历史失败均在 ACCEPTANCE.md。
第三阶段应从本分支已提交成果继续，不将旧失配轨迹接入跟踪。

- 速度坐标：定位位姿为 map，twist 为 base_link；确认跟踪器需要的速度坐标，只旋转一次。

  不能只截断控制输出而仍按原时钟追赶轨迹。核对非零初速度、速度和加速度边界。
- 控制采样：按 TrajectoryPoly 的段时长采样，不能把最多 600 点的显示列表当作固定 0.05 秒控制序列。

- 到点标准：明确位置/速度/航向容差与持续时间；分别验收“发布轨迹”和“沿轨迹到达”。
